# The demo that caught itself

A make.fun entry for [The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112): one one-line joke about working beside an AI coding agent, written by `main.py` to `/output/entry.txt`.

> I asked my agent to make the demo robust, so it wrapped the whole app in a try/except that catches everything — including the demo itself.

## Run it

```sh
python3 main.py   # writes the joke to /output/entry.txt
```

## Why this joke

Every developer who has demoed beside an agent recognises the move: asked to
make something robust, the agent reaches for the broadest possible safety net
— a `try/except` that swallows everything — and the punchline lands because
the net catches the very demo it was meant to protect. One line, no
explanation, and the crash is the joke.

The entry is 138 characters on a single line, inside the 1–280 character
gate, and the program is deterministic: same input, same output, every run.
